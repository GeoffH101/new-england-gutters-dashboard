1. Point QuoteIQ's webhook here (live data)

In QuoteIQ: Settings → API Integrations, register this URL to receive Estimate and Schedule events:

If QuoteIQ shows you a signing secret or lets you set a shared secret when you register the URL, that value must match QUOTEIQ_WEBHOOK_SECRET in this app's environment variables (set it in Railway → your service → Variables). Until it's set correctly, incoming webhook calls are rejected with 401 — check the server logs if events aren't showing up.

2. Check whether webhooks are arriving

Trigger a test event in QuoteIQ (e.g. create or edit a test estimate), then click refresh below. A REJECTED_AUTH entry means the call arrived but the secret didn't match — check received_headers in that row to see what QuoteIQ actually sent, and update QUOTEIQ_WEBHOOK_SECRET in Railway to match.

3. Backfill past data from a CSV export

Export your existing jobs/estimates from QuoteIQ as CSV, then upload it here. Nothing is sent anywhere except this app's own database — the file is parsed in your browser.
